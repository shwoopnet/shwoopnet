research-data: public Kalshi market data and research databases for kalshi-scalper (made 2026-10-29 by the first research session).
Note: the Oct 20 archive (MANIFEST.md, restore.sh, *.xz) is kept alongside; this Oct 29 archive is newer and is the one to use for kalshi-scalper/data.
Contents: one gzipped tar of kalshi-scalper/data (sources only), split into 45 MiB chunks. FILES.txt lists every file inside.

Reassemble (from an empty folder):
  git fetch origin research-data && git worktree add rd origin/research-data && cd rd
  sha256sum -c MANIFEST.txt --ignore-missing
  cat research-data.tar.gz.part-* > research-data.tar.gz && sha256sum research-data.tar.gz   # compare with the WHOLE line below
  mkdir -p ../kalshi-scalper/data && tar xzf research-data.tar.gz -C ../kalshi-scalper/data

Not included (rebuild commands in kalshi-scalper/HANDOFF_V2.md section 4): derived numpy arrays, sc1.sqlite, fp3*.sqlite, lag2_*.json, sweep1_*, the owner's live order exports (private, not market data).
