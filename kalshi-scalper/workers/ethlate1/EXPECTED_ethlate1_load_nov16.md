REFUSES unless HELDOUT_PULL_RUNS.md carries a line with the mark "readable ONLY by Desk B's ETHLATE1 loader", "ethlate1_load.py" and this file's own sha256 (Main adds it after Auditor B signs; no flag, no env var). Wall: only date directories 2026-10-27 to 2026-11-15 are listed (a directory dated 2026-11-16 or later is never opened); every ladder row's `close_time` is read FIRST and a close before 2026-10-28T00:00:00Z (1793145600) or at or after 2026-11-16T00:00:00Z (1794787200) is dropped and counted before any other column; then `ticker` must start with "KXETHD-" (else dropped and counted); then `status` must be "active"; then prices.
