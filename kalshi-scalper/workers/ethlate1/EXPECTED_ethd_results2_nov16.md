# ETHD_RESULTS2 job generator: expected figures, written BEFORE the code (Desk B, Nov 16, 2026; Auditor B's structure FAIL of ETHD_RESULTS)
**Why:** ETHD_RESULTS (a paged settled list of the whole KXETHD series) stopped at its 40 page cap with a cursor left: KXETHD has about 330 strikes an hour (about 8,000 a day), so the window is about 150 pages and 300 MB. My estimate "15 to 35 pages" was wrong by a factor of about 5 (I had taken the recorder's 40 strikes an event for the series size). The run is void and unlisted. **Fix:** ask only for the strikes the recorder stored.
`build_ethd_results2_job.py <quote-data checkout> [out.json]`: reads, from `quotes/<date>/<HHMM>/ladder.csv.gz` for date directories 2026-10-27 to 2026-11-15 only, ONLY the columns `ticker` and `close_time`, in that order: a row whose ticker does not start with "KXETHD-" is dropped and counted before any other column is parsed; then a close_time outside [2026-10-28T00:00:00Z, 2026-11-16T00:00:00Z) is dropped and counted; the kept tickers are collected as a set. No price, size, status, strike or time of receipt is parsed. Output: a kalshi-pull job `ETHD_RESULTS2`: GET /markets with `tickers` = up to 100 sorted tickers a request and `limit` 100 (no status, no date param), `ticker_allowlist` = the kept tickers, `series_allowlist` ["KXETHD"], `max_requests` = requests + 12, 5.0 s pacing, three-429 stop. Prints counts (tickers kept, requests, drops) and the sha256 of the job file.
