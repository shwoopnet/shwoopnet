# NC15 place counts file: definitions and hand case, written BEFORE the code (Testing Desk, Nov 16, 2026; the Head's order of 16:06Z)
Purpose: the page's seven NC15 depth-cell rows show each place's real count of fill-checked signals toward the lane's block bar of 60. One file, `nc15_place_counts.json`, counts only. The counting core is Desk A's nc15_wheel_counts.py (the frozen v4 sheet, 8679f760); this wrapper does not rewrite it: it imports the core by path, REFUSES unless the core's sha256 is the pinned one, calls its counting function with the start time and writes the JSON. The core reads book columns only (never a result, trade or outcome column); the wrapper reads nothing but the core's returned counters.
## Definitions
- Places (the admit list's seven NC15 depth-cell places, docs/WHEEL_ADMIT_LIST.md, scripts/sync_registry.py ids): WH-NC15-SILVER (KXSILVER15M), WH-NC15-COPPER (KXCOPPER15M), WH-NC15-WTI (KXWTI15M), WH-NC15-HYPE (KXHYPE15M), WH-NC15-BNB (KXBNB15M), WH-NC15-USDCAD (KXUSDCAD15M), WH-NC15-NATGAS (KXNATGAS15M), in that order. START TIME OF THE FORWARD COUNT = 2026-11-13T02:40:00Z (epoch 1794451200); only signals whose signal poll's exchange time is at or after it count (the core's filter).
- The count of a place = the core's "fill-checked" counter of its series: the signal poll and the next poll (at most 6 s later) each show at least 10 contracts at or under touch + 1c, the signal in the cell (|imb5| >= 0.50) with the implied ask 0.10 to 0.90. Progress toward the target 60 is that count; no result, no settled field.
- File: {"places": [{"id", "fill_checked_signals" (a non-negative integer), "target": 60, "start_utc": "2026-11-13T02:40:00Z", "as_of_utc"}, ...seven rows in the order above]}. Nothing else: no dollar figure, PF, price, result, per-day rate or series ticker. as_of_utc = the run's own time, given on the command line as an ISO UTC time ending in Z (the workflow passes date -u); the same value in every row.
- Refusals: the core's sha256 differs from the pinned one; the allow-list file has no line for this job naming the wrapper's and the core's sha256 (the Auditor B line); a series missing from the core's answer, or a counter that is not a non-negative integer; an as_of that is not YYYY-MM-DDTHH:MM:SSZ. The output is written to a temporary file and renamed, so a failed run leaves the previous file whole.
