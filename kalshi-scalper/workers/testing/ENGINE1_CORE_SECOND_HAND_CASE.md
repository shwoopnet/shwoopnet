## Interface as I read it (Desk A amends anything I read differently)
Entry: id, close_ts, day, series, side yes|no, ask (the side's raw ask at the entry candle), n (contracts; the aggregate can override with 1 or 10), entry_end, result yes|no|void. Path: candles AFTER the entry candle with end_ts <= close_ts, (end_ts, yes_bid, yes_ask), sorted. A candle is SELLABLE only if 0 < yes_bid < yes_ask < 1; the side's sellable bid is yes_bid (YES) or 1 - yes_ask (NO); an unsellable candle is never a trigger and never an exit price. paid = min(round(ask + h, 6), 0.99). Exits, each priced separately: H hold to settlement; T the first sellable candle whose bid >= min(2 x paid, 0.99) is sold at max(bid - h, 0.01), else settlement; S the first sellable candle with bid <= paid / 2, same pricing, else settlement; B the first sellable candle where T or S triggers (both on the same candle: the stop wins), else settlement; M180 and M60: sold at the candle ending EXACTLY close_ts - 180 (-60) at its bid - h (floored 0.01); that candle missing or unsellable: counted "no mark", no cash (an entry with entry_end after close_ts - 180, resp. - 60, is also "no mark" for that exit). Trigger comparisons are made on values rounded to 6 places (MY READING: it removes float noise; so a bid equal to the threshold triggers). Fee: fee_up_order(p, n) = ceil(round(0.07 n p (1 - p) 100, 9)) / 100, per order per leg (entry at paid and n; an early exit pays a second at the exit price and n; hold pays none). Settlement: a win pays n x 1, a loss 0; a void refunds paid x n and keeps the entry fee (cash = -fee_in); a void after an early exit changes nothing (MY READING: Desk A silent). cash = proceeds - n x paid - fees. Per contract = cash / n.
Aggregate per rule, per h in (0, 0.01, 0.02) and per n: n (scored entries; "no mark" ones are not scored), wins (cash > 0), net, PF (infinite with no loss and a win, nan with neither, 0 with losses and no win), halves floor(n/2) by (close_ts, id), day-clustered z (UTC day sums, mean over sample sd / sqrt(days); None under 2 days or sd 0), trade_days, exit counts target, stop, time, settle, no_mark. Tolerance 1e-9.
