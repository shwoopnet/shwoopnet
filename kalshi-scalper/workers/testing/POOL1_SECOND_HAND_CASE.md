## My readings where the spec text leaves a choice (all to be confirmed or corrected by Desk A; a 1e-9 compare will expose any other difference)
R1 A candle is a key end_ts -> (bid, ask) of its closes; usable = 0 < bid < ask. "has a candle" = the key is present. Pool name rule: at least 5 distinct ET dates with any candle key and at least 2 funding prints.
R2 Trading dates D = the distinct ET dates with the key (day start + 09:31 ET) present for at least one name. Per name the entry candle must also be usable, else the name is skipped for that date (counted "no_entry").
R3 sigma: the 60 returns ln(mid_t / mid_(t-60)) for t = e - 3540, e - 3480, ..., e (60 values of t); a return counts only if the candles at t and t - 60 are both usable; fewer than 45 counted returns: entry skipped, counted "no_vol". Population sd (divide by the count of returns). u = sigma x sqrt(30).
R4 Gap: previous trading day = the latest earlier ET date for which the name has the key (day start + 16:00 ET); that candle or the 09:31 one unusable: skip (counted). g = mid(09:31) / mid(prev 16:00) - 1; class c in {30, 60, 100} bp: |g| >= c / 10000 compared after rounding both to 9 decimals; FOLLOW long if g > 0, FADE the opposite.
R5 Funding level: rate_D(name) = rate of the latest print with ts < e (e = D's 09:31 ET end) and e - ts <= 36 h. Names with a rate_D are ranked (rate desc, ticker asc), N of them; N < 3 skips the date; top = first ceil(N/3), bottom = last ceil(N/3). FADE = short top, long bottom; FOLLOW the reverse. Names ranked do not need a usable entry candle (the skip happens at entry). Funding change: chg = rate_D - rate of the print just before the latest one, which must exist with latest_ts - prev_ts <= 60 h; ranked the same way over the names that have a chg.
R6 Carry: for every name and print time T: entry end = T - 1800, last rate = the latest print with ts < entry end (none: no candidate), side = receives it (rate > 0 short, rate < 0 long, 0 no candidate); the day = the ET date of the entry end; candidates of that ET date are ranked by |last rate| desc then (ticker, T) asc, M candidates (distinct names must be >= 3, else the day is skipped); carry A takes the first ceil(M/3), carry B the first ceil(M/2); exit end = T + 1800; both candles usable else "no mark". Funding booked from the prints (the print T is strictly inside).
R7 Cooldown: a name's next entry of the SAME rule needs e >= the previous trade's exit end. One position per name per rule. Order of checks: signal condition, cooldown (counted "blocked"), sigma, exit.
R8 Exit: tested on candles ending e + 60, e + 120, ..., e + 60 T in order; unusable ones are skipped; first hit wins, stop before target; no hit: the candle e + 60 T must be usable, else "no mark". If e + 60 T is after the name's last candle key at all: "no mark" even when an earlier candle would have hit (the spec's last sentence read literally). Hit tests use the raw bid or ask (not haircut); the exit price is the leave price (bid x (1 - h) long, ask x (1 + h) short) at the exit candle.
R9 Gate per rule, each haircut run on its OWN trade set (halves = the first floor(n/2) of THAT set sorted by (entry end, ticker)): n/trading days >= 3 at h = 0.0002, PF(0.0002) >= 1.3 and PF(0.0005) >= 1.0 overall and in each half, no ET day (of the entry end) with net above 30% of the total net, total net at h 0.0005 > 0. PF with no losses = infinity (passes), no trades fails. n counts only funding-booked trades; net = gross - 2 x 0.0012 - funding (long pays, short receives).
