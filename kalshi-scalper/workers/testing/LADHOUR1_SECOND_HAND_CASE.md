# LADHOUR1 second build (Testing Desk), hand case, Nov 16, 2026. Written blind from Desk B's spec and card (LADHOUR1.spec.json, LADHOUR1_CARD.md on claude/idea-desk-b, spec 30aee0c4) BEFORE any code. Invented numbers only. FORWARD card: no data exists yet.
LADHOUR1 is ETHLATE1's mechanism on four hourly ladders (KXINXU, KXNASDAQ100U, KXWTIH, KXGOLDH): 96 rules per series (12 bands x 4 filter values x 2 exits, cheap side, bucket 120), 384 in all, 2c primary, one engine run PER SERIES with its own split and its own spread cuts. My build reuses ethlate1_second.py (E1 to E10, the amendments: one entry per market, bands by cheap cents // 5, the 40 event floor on scored trades, 3 a day in SEARCH only, upper tail BH) and adds a per-series wrapper. Readings L1 to L6, please confirm or correct:
L1 Series wall: a ticker belongs to a series iff it starts with the series code followed by '-' (KXINXU-, KXNASDAQ100U-, KXWTIH-, KXGOLDH-); the wall is compared first. KXINXU- must not match KXINXUD-style codes; KXNASDAQ100U- must not match KXNASDAQ100-.
L2 Each series is scored alone: its own SEARCH and VALIDATE halves (the floor(D/2)-th distinct close date of that series' entries, to be replaced by Desk A's dated constant per series), its own spread cuts from its SEARCH half, its own gates; nothing is pooled across series except the denominator of BH.
L3 m for BH on each series' VALIDATE p = m_carried (the one number fixed on the day the spec is frozen, an argument) + 384, printed first. Each series is read once (the process), so the BH applies to that series' VALIDATE passes with the total m.
L4 The gates are ETHLATE1's: n >= 100 scored trades, 2c PF >= 1.3 with both halves >= 1.0 (halves by (close_ts, ticker)), trade days >= 10, signals a day >= 3 over the SEARCH span (SEARCH only), events floor 40 on scored trades (the card lists only min_n, pf, days, signals per day: please say if the 40 event floor applies to LADHOUR1 as it does to ETHLATE1), PF at 1c printed not gated.
L5 Candles, look, M60 mark, fees, cheap side, whole-cent spread classes: as ETHLATE1 (the recorder file layout is the same ladder.csv.gz; the loader waits for the data and the allow line).
L6 'each series is read ONCE when its SEARCH and VALIDATE halves each hold the registered n, or after 60 days' is a process rule, not scored logic; the build prints counts first and scores only when told to.
