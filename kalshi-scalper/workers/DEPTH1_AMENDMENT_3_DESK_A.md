The registration says "0 or undefined: no trade". f3, f8 and f9 are differences of quantities that are often equal; V2's trade rule (`v == 0`) trades on floating point residue near 1e-17. For ALL TEN features a value whose absolute size is at or under 1e-12 is ZERO, no trade. It is applied once, to the features of every window (inside the wrapper's window_record, after V2's own function returns), so the trade rule, the shuffled-book control and the no-label noise description all see the same zero. A value above 1e-12 is untouched. No feature function is changed (their hashes are V2's, frozen). Printed beside the verdict as information: per try, how many scored windows had a raw feature within 1e-12 of zero but not exactly zero.
(h) THE Z. The verdict reads the CLUSTER-CORRECTED z against the 5.27 bar: z = mu / sqrt( (D/(D-1)) x (1/n^2) x sum over US Central close dates d of ( S_d - k_d x mu )^2 ), where mu is the mean net per trade, n the trades, S_d the sum of net per trade on date d, k_d the trades on date d, D the number of date clusters in that try; D < 2 or variance 0 gives 0. The uncorrected z (the same without D/(D-1)) is printed beside it, per try, as information (the block "Z BESIDE"); the bar 5.27 (N 728,648, one sided, alpha 0.05) and the shared 5.46 do not change. ## The shuffled-book control, as a written procedure (so a second build can reproduce it)
numpy default_rng(20261114), one generator for the whole control (numpy 2.5.3, PCG64). Per market in the order KXGOLD15M then KXBTC15M, its scored windows in scored order (run path order, then coverage order within a run). For each try in the order gold f1 to f10, then Bitcoin f1 to f10 (20 tries), the sign vector sg is +1 where the feature value is above 0, -1 where below 0, 0 where None or zero (after the zero rule), with the window's YES net pnl vector py and NO net pnl vector pn (NaN where that side has no fill). mean_net(sg, py, pn): value = py where sg > 0, pn where sg < 0, NaN elsewhere; drop NaN; if fewer than 30 values, -1e9; else the mean. Observed value per try = mean_net on the real sg. For each of 1,000 rounds: for each of the 20 tries in that fixed order, ONE call rng.permutation(len(sg)) for that try, mean_net(sg[perm], py, pn); the round's best is the maximum of the 20 values (a -1e9 value never wins unless all are). Threshold = np.percentile(best, 99) with numpy's default linear interpolation (index 0.99 x 999 of the sorted 1,000). A try passes the control if observed > threshold. Marginal p = (1 + number of rounds with best >= observed) / 1001. The draws are independent per try (Head's ruling of Nov 13; the stricter control).
