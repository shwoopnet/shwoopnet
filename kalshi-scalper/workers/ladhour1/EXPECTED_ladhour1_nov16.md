# LADHOUR1 loader, job generator and adapter: expected figures, written BEFORE the code (Desk B, Nov 16, 2026)

Scope: forward only. Four hourly ladders: KXINXU (S&P 500), KXNASDAQ100U (Nasdaq-100), KXWTIH (WTI), KXGOLDH (gold). Same shapes as the signed ETHLATE1 package (ethlate1_load.py, build_ethd_results2_job.py, ethlate1_run.py); everything below that is not named is copied from there.

## Loader `ladhour1_load.py`
- Window constants START and CUT are `None` until Main writes start_utc and the read date (spec: PENDING). `load()` raises "REFUSED: window not set" while either is None. The date directories listed are those from START's UTC date to CUT's UTC date inclusive, computed from the constants (no hard-coded list).
- Wall: ticker FIRST, prefix one of KXINXU-, KXNASDAQ100U-, KXWTIH-, KXGOLDH- (the dash is part of the prefix, so KXINX- or KXNASDAQ100- would not pass); a wrong-series row has no other column read (trap test). Then close_time in [START, CUT); then status active. Candles = last row of each clock minute, end_ts = (floor(t/60)+1)*60, candles ending after the close dropped and counted.
- Results: one landed run folder PER series, folder name `LADHOUR1_RESULTS_<SERIES>` (check_run_name requires the parent directory name to equal that for the series); the allow-list line must carry the mark "readable ONLY by Desk B's LADHOUR1 loader", "ladhour1_load.py", the file's own sha256 and the run stamp. A manifest row with status not 200, truncated or without a file raises "RUN VOID". Results yes, no, void kept; others dropped and counted. A result row's ticker is checked against ITS series prefix only (a KXINXU run never feeds a KXWTIH market).
- Output: {series: [market]} with market = {series, ticker, close, result, candles}.

Made-up fixture (internal functions, no file): window 2026-11-20T00:00Z to 2026-11-21T00:00Z (START 1795219200 is wrong to type by hand, the test computes it with calendar.timegm). One KXINXU ticker `KXINXU-26NOV2014-T7000.99` closing 2026-11-20T14:00:00Z = START + 50400 s, rows 148, 130, 118, 70, 50, 5 and -3 seconds before the close with the same bids and asks as the ETHLATE1 loader test (0.28/0.32, 0.30/0.34, 0.31/0.33, 0.32/0.34, 0.35/0.37, 0.40/0.42, 0.90/0.92). Expected candles: (close-120, .30, .34), (close-60, .32, .34), (close, .40, .42), the row 3 s after the close is dropped and counted. A KXINX- row (wrong prefix, trap) is dropped by ticker alone. A KXINXU row closing exactly at CUT is dropped by close_time (trap on every column but ticker and close_time). Counts expected: kept tickers 1; candles 3; dropped by the cut 1; outside the wall 1; candle after close 1.
Window not set (START None): `load` raises REFUSED before reading anything.

## Job generator `build_ladhour1_results_job.py <SERIES> <quote-data checkout> [out.json]`
Reads ONLY ticker then close_time of the series' ladder rows in the window; writes one kalshi-pull job `LADHOUR1_RESULTS_<SERIES>` asking for those tickers (params only tickers and limit 100; allowlist equals the kept set; series_allowlist the one series). **Page cap sized from the data:** requests = ceil(kept/100), max_requests = requests + 12 (never a fixed number), and the generator prints kept, requests, max_requests and refuses (exit 1) if kept is 0 or requests exceed 1,100 (the runner's 1,200 limit less the 12 repeats and margin). Fixture: 250 distinct tickers of the series, 3 outside the wall, 2 outside the window, 1 unreadable close_time, duplicates of one ticker: kept 250, requests 3 of 100, 100, 50, max_requests 15.

## Adapter `ladhour1_run.py` (no new scoring code)
Same pinned engine files as ETHLATE1 (the split pin changes when Desk A writes the four constants), same C8 gate, same events rule (distinct closes of scored trades), 3 signals a day in SEARCH. Per series 96 cells; BH PER SERIES over the one m_total = m_carried + 384 (Nov 16 correction, the Testing Desk L3: the spec reads each series once on its own date, so p-values cannot be pooled). `run(markets_by_series, m_total)` REFUSES if any series in the data lacks a dated constant in engine1_split. Hand case (test_ladhour1_run.py, the ETHLATE1 hand markets on series KXINXU, S.LAST_SEARCH["INXU"] set to a made-up date): run refuses while m_total is None; refuses without the dated constant; cells selected 384; 4 cells scored; 120 SEARCH markets for KXINXU and none for the other series; no pass (the same 120 markets pass the 1c gate at PF 1.337 but not C8's 2c gate, 1.272; the ETHLATE1 hand case, which already checked those figures).
