# PERPGEN CRYPTOCTX amendment (worker note, 2026-11-06; discloses one counting defect, changes no bar, cut or grammar rule)

**Defect found in `workers/PERPGEN_PROTOCOL.md`:** the Features section says "33 numeric features, 4 categorical" and the grammar says "330 numeric atoms plus 19 categorical". The feature list written in the same section has **34** numeric names: r5, r15, r60, r240, r1440 (5); vol60, vol240, volratio, rng60, rng240 (5); sp, spr (2); vlr15, vlr60, doi60, doi240, tvm (5); fr_last, fr_chg, fr_avg3 (3); dhi240, dlo240, dhi1440, dlo1440, pir1440 (5); xbtc15, xbtc60, xbtc240, xeth60, xeth240, xgold60, xus500_60, rel_btc60, rel_btc240 (9). That is 5+5+2+5+3+5+9 = 34 numeric features, hence 340 numeric atoms plus 19 categorical = 359 atoms.
**What this worker did:** used the explicit list (all 34 names), because the list is the registered text and dropping one name would be a silent choice. Nothing else in the protocol is changed. The other generator workers may have read the count differently; the count affects only how often each feature is drawn.

**Detail the protocol left open, fixed before any rule was scored (also in the docstring of `src/scalper/perpgen_cryptoctx.py`):**
- Rule sampling: k atoms (0.2, 0.4, 0.4 for 1, 2, 3), k DISTINCT features drawn uniformly from the 38 feature names (34 numeric, 4 categorical), operator and quantile level (or categorical value) uniform; a draw with no CONTEXT feature (fr_last, fr_chg, fr_avg3, the nine cross-asset features, hod4, dow, wkend, mtf) is redrawn (this worker's slice), direction and horizon uniform.
- Open position: a signal at decision time t is ignored while t is before the exit time of the ticker's open position, so a 15 minute hold (exits 16 minutes after t) blocks the next quarter hour.
- Stage-one leader features: validation data cannot be read before the freeze, so at stage one a leader value exists only where the leader's DISCOVERY data covers t (stricter than the protocol, never looser). Consequence: xgold60 and xus500_60 are missing at every crypto discovery time (gold and US 500 discovery regions start in September and October) so rules containing those atoms cannot trade in discovery; they are still drawn and counted in N.
- vlr is log((S + 1) / (A x w + 1)) (S window sum of notional volume, A trailing 1,440 minute mean per minute), so a window without volume is finite.
- The fill-quote defect screen (10 x the ticker's discovery median spread or 100 bps) applies at the entry fill and at the exit fill.
- Dedupe is against ledger files whose name contains CRYPTO (the same canonical string in another group is a different (rule, group) pair). Rules are written `feature>=q0.75&feature2==3|long|60` (atoms sorted by feature name, horizon in minutes).
