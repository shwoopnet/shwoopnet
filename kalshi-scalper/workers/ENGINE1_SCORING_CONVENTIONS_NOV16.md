# ENGINE1 scoring conventions as text (Desk A, 2026-11-16), written for Forensics' blind second build. Source of every line: engine1_core.py (53317e4b), engine1_enum.py (e42ee1a4), engine1_driver.py, engine1_split.py, as run for run 2. No code here.

Candle = (end_ts, yes_bid close, yes_ask close, last, volume, open interest). A market's candles are used only if end_ts is at or before its close_ts. cents(x) = ceil(round(100 x, 6)) (whole cents rounded UP).

**1. Bucket.** Bucket B (120, 180, ..., 840, steps of 60) means the entry candle is the candle whose end_ts equals close_ts minus B exactly. There is at most one such candle, so there is no "first of several". If it is absent: no entry (counted "no entry candle"). The entry candle must be two sided: 0 < bid < ask < 1, else no entry.

**2. Band and side rule.** At the entry candle: yes ask in cents ya = cents(ask), no ask in cents na = cents(1 - bid). cheap = the side with the lower cents ask (tie: yes); favourite = the side with the higher cents ask (tie: yes); yes and no are as named. a = that side's cents ask. The rule applies only if 5 <= a <= 94, and its band = a // 5 (so band k covers a = 5k to 5k+4 cents: band 1 is 5c to 9c, band 18 is 90c to 94c; closed on whole cents, no open ends). The entry is scored at the RAW ask of that side, not the rounded one: yes raw ask = ask, no raw ask = 1 - bid. One entry per market per rule.

**3. Filters.** Features use only candles with end_ts at or before the entry end e, looked up by exact end_ts (e - lag). oi3 = oi(e) - oi(e - 180); oi6 = oi(e) - oi(e - 360); both candles must exist and carry a non-null oi, else MISSING. vol3 = (vol(e) + vol(e-60) + vol(e-120)) - (vol(e-180) + vol(e-240) + vol(e-300)); all six candles must exist and carry a non-null volume, else MISSING. mom k (k = 1, 3, 5) = mid(e) - mid(e - 60 k) of the SIDE BOUGHT, mid = (bid + ask)/2 of the yes quote for a yes side and 1 - that mid for a no side; the candle e - 60 k must exist (it need not be two sided), else MISSING. Class of a number x: "up" if x > 1e-12, "down" if x < -1e-12, else "flat". A filter (feature, class) keeps the entry if the class equals it; a MISSING feature drops the entry (counted "missing feature candle"). spread feature = cents(ask - bid) of the YES quote at the entry candle (whole cents, rounded up); classes from terciles: for each series AND each bucket, take the spreads (cents(ask - bid)) of every SEARCH market's candle ending at close - bucket with 0 < bid < ask < 1; sort ascending (n values); c1 = the value at position ceil(n/3) (1 based), c2 = the value at position ceil(2n/3); "low" if spread <= c1, "mid" if <= c2, else "high" (all inclusive upper edges). The cuts come from SEARCH only and are applied unchanged to VALIDATE.

**4. Exits.** path = the market's candles with entry_end < end_ts <= close_ts, ascending. H: hold to settlement: the payoff is 10 (contracts) if the side bought equals the result, else 0; a void result refunds the price and keeps the entry fee (net = minus the entry fee). T (target): on the first path candle with end_ts <= close - 60 and 0 < bid < ask < 1 where the SIDE's bid >= min(2 x paid, 0.99) (tolerance 1e-12), sell at max(bid - h, 0.01); side bid = yes bid for a yes side, 1 - yes ask for a no side. S (stop): the same candles, the first where the side bid <= paid / 2 (tolerance 1e-12), sold at max(bid - h, 0.01). B (both): the same candles, the first where either the target or the stop holds (target is tested first and names the reason); sold the same way. If T, S or B never trigger, the trade holds to settlement as in H. M180 and M60: the mark candle is the candle whose end_ts equals close - 180 (or close - 60) exactly; if the entry end is after the mark, no trade (counted "too late"); if the mark candle is absent or not two sided, no trade (counted "no mark"); else sell at max(side bid - h, 0.01).

**5. Price paid, fees, net.** paid = min(raw ask + h, 0.99), h in {0.01, 0.02}. fee(p, n) = ceil(round(0.07 x n x p x (1 - p) x 100, 9)) / 100 dollars per order (n = 10 contracts). An early exit pays fee(exit price, 10) as well as the entry fee(paid, 10); a hold to settlement pays only the entry fee. Net for 10 contracts = round(exit price x 10 - paid x 10 - fee_in - fee_out, 9), or at settlement round((10 if win else 0) - paid x 10 - fee_in, 9). n of a rule = the number of entries that produced a net (entries with no mark or too late are not counted). PF = (sum of positive nets) / (sum of absolute negative nets); n and PF at h 0.01 are the "1c" figures and at 0.02 the "2c" figures; halves = the first floor(n/2) and the rest by market close time then ticker.

**6. Split.** A market's phase is by its UTC close date: SEARCH if the date is at or before the series' LAST_SEARCH date, else VALIDATE. LAST_SEARCH for the series in the listing (constants in engine1_split.py, fixed before any read from the union of archive and NC15 distinct close dates, floor(D/2)): BNB 2026-09-03, BTC 2026-09-03, DOGE 2026-09-03, ETH 2026-09-03, GOLD 2026-09-03, HYPE 2026-09-03, NEAR 2026-09-03, SILVER 2026-09-03, XRP 2026-09-03, ZEC 2026-09-03, SOL 2026-09-07, WTI 2026-09-04 (also COPPER 09-13, NATGAS 09-14, EURUSD 09-27, GBPUSD 09-27, USDJPY 09-27, PALLADIUM 09-24, PLATINUM 09-24). Use these as given: they are inputs, not something to recompute from your extract, because the listing's n depends on them. VDAYS and SDAYS in the ranking spec use the same dates.
