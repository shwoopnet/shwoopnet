# Rules for every V2 worker (read first)

- Research only. Never edit `functions/`, `index.html`, `firestore.rules`, `.github/`, or anything that trades. Never deploy, never merge, never push to `main`. Branch: `claude/epic-ptolemy-0amjd9`.
- Never `git add -A` or `git add .`; add only your own files by name. Never commit anything under `kalshi-scalper/data/` (ignored; it may hold private rows). Commit with `git pull --rebase origin claude/epic-ptolemy-0amjd9` then `git push origin claude/epic-ptolemy-0amjd9`; on a conflict in a file you did not write, keep both sides.
- Do NOT edit `kalshi-scalper/README.md` or `kalshi-scalper/V2_STATUS.md` (the lead merges them). Write your registration to `kalshi-scalper/workers/<ID>_REGISTRATION.md`, commit and push it BEFORE any scoring, then your result to `kalshi-scalper/workers/<ID>_RESULT.md`.
- A registration names: the rule exactly; the counterparty (who loses money and why); a numeric prediction; kill criteria; the universe chosen on time or cost only, before the entry look (never from quotes after the entry time); three windows by date (the last is a holdout read once); fees 7% x C x p x (1-p) rounded up to the cent per order at C = 1 and 10; fees x1.2 check; entries filled strictly at a quote you could hit at or after the signal candle; zero-volume candles reported both ways; the number of variants tried (N), each counted.
- Verdict words only: FALSIFIED, NOT_YET_FALSIFIED, NOT_ENOUGH_DATA, NOT_RUNNABLE. No "works", "ready", "promote". The bar for a strategy: PF at least 1.5 in each of three windows after fees, positive at fees x1.2, a named counterparty, deflated z at the bar for N about 439,000 (z about 5.17). A pass earns only a forward test registration.
- Check the ledger first (`kalshi-scalper/README.md`, `studies/SCOREBOARD_2026-10-28.md`, `studies/NOVIEW_MECHANISMS_2026-10-28.md`): if your idea is a reworded tested one, stop and say so instead of spending a try.
- Public data only, no keys. Kalshi's public API rate-limits (HTTP 429); `scalper.api._get` waits it out; keep at most 2 Kalshi request streams of your own, with pauses of 0.5 s or more.
- Never print, echo or write the value of any environment variable that holds a token. Live order rows are private: keep them in `/tmp/claude-0/-home-user-shwoopnet/026f6e8f-6dc4-5e3b-8c3b-e0089b12fb94/scratchpad/`, never in git; aggregates (PF, counts, net by market) may go in your result file.
- Do not message other sessions. Finish with a short report: what you registered, verdict with numbers (PF per window, n, N tried), files.
- Run Python from `kalshi-scalper/` with `PYTHONPATH=src`. Scratch files go in the scratchpad above.
