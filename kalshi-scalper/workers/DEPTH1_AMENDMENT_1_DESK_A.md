# DEPTH1 Amendment 1 (Nov 12, 2026; written by Idea Desk A on the Head of R&D's word; before Nov 14 00:00Z and before any R6 outcome was read)
V2's `depth1.py`, its registration and its frozen hash (8eb6aa38...eeb69) are NOT changed. The read is run through `desk_a_verify/depth1_wrapper.py`, which patches three functions at run time. Where this text and V2's `CONFIG["usable"]["result"] = "yes or no"` differ, this amendment governs.

1. **(a) Usable windows.** `usable()` may drop a window only for reasons known at or before the decision (no book, no quote, coverage, outside the band). It may NOT drop a window because its result is missing or not yes/no. (Installed: V2's `usable` is called with the result field set to "yes", so every other test is V2's own.)
2. **(b) No-result fired windows.** A window where a feature FIRES and there is no yes or no result is booked as a **fee-only loss** (price refunded, fee kept; net = minus the fee; stress = minus 1.2 fee), counted in n, PF and z, with the count and the raw result values printed (line "AMENDMENT 1 COUNT"). A true void is booked the same way. (Same as ESOCTIE NOTE 4 and the Head's single void rule.)
3. **(c) Windows where no feature fires** are unaffected.
4. **(d) Closed-family features.** `f6_thin_depletion` and `f7_sweep_net` are printed as separate lines under their own header ("CLOSED-FAMILY FEATURES, REPORTED SEPARATELY"), fixed now; nothing that rests on either alone can become a lead; the headline is judged on the registered whole (20 tries, the registered bar, z 5.27 with 5.46 beside it).
5. **(e) Default-closed.** V2's `run()` refuses before 2026-11-14 00:00 UTC, on a second run (result file) and on a started marker; the wrapper adds no path around it.
6. **Stop rule.** If fired windows with no yes/no result exceed 1% of fired windows, the wrapper stops BEFORE a verdict line is written (a data gap on a 15 minute series, not voids), prints the count, and leaves the started marker so the run is not repeated; the Head decides.
7. **(f) Printed before the verdict lines, cannot change them (Head, Nov 12, built into the wrapper):** V2's registered no-label noise description (per market: share of looks where f1 changes sign between the decision poll and either of the next two 2 s polls, and the same for the single-poll size features f2, f3, f8, f9, f10; f4, f5, f6 need earlier polls and f7 the tape, so they are not in it), the median fill delay per market, and how many otherwise-eligible windows each `usable()` condition removed (counted from the coverage row for the report only; V2's function decides). It reads no outcome.
8. **Tests.** `desk_a_verify/depth1_dryrun.py` (synthetic R6 fixture, no edge): clean run FALSIFIED and second run refused; 0.5% no-result windows booked fee-only and counted (4 of 620, verified `pnl = -fee`); 5% no-result windows stop before the verdict; f6 and f7 lines printed; noise description, median fill delay (2.0 s on the fixture) and condition counts printed.
