Everything registered as a forward read is read once, with one command, on fresh days only. Nothing here places an order.

1. `cd kalshi-scalper && git pull` on branch claude/epic-ptolemy-0amjd9 (the code and tests are committed).
2. Refresh the fresh candles (public data, resumable, about 1 hour; if the worker restarts, run it again):
   `PYTHONPATH=src setsid nohup python3 -m scalper.fresh_update > data/fresh_update.log 2>&1 &`
   Check with `ps aux | grep fresh_update | grep -v grep` and `tail data/fresh_update.log`.

4. The registered read, once: `PYTHONPATH=src python3 -m scalper.fwd_reads read` (refuses before 30 fresh days / 2026-12-01, and refuses a second run).
