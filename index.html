Methodology
Real 15-minute bars for all 16 universe symbols (Twelve Data, exported from the live dashboard — this sandbox has no direct market-data access, so the export was the only way to run this honestly on real prices). Signal detection, the trailing-stop rule, and the slippage/cost model are a line-for-line port of the dashboard's own simulateORBForwardSameDay + applyORBSlippage backtest engine — not a reimplementation from the live-monitoring code, which turned out to matter: an earlier attempt at this reproduced a real, previously-fixed bug in that engine's own history (roughly doubling the reported win rate and profit factor) by checking the entry bar's own high/low instead of starting the walk one bar later. Position sizing (1% risk per trade, 20% max-per-position, 5.5% total-risk ceiling) is the exact computeSizedOrder logic the live system runs, applied against a running $10,000 balance — so this reflects real compounding and real risk-ceiling skips, not a flat per-trade normalization.

One genuine finding worth flagging: a large share of signals (see the breakdown alongside) fire on the literal last 15-minute bar of the session — closing-auction volume on these names frequently exceeds 2× the 20-bar average, which is enough to trigger the volume-confirmation check with no trading day left to act on it. The backtest engine treats these as flat, small-loss trades (one leg of slippage, no real price movement) rather than manufacturing a fake win — the live system would do the same in practice, since the market-close handler closes any just-opened position within seconds regardless.
