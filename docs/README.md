# docs

These files are working notes, not part of the app. They are excluded from the public GitHub Pages site by `_config.yml`.

| File | What | Refresh |
|---|---|---|
| `PROJECT_OVERVIEW.md` | What the system is, how the bot works, safety, research state, quality, incidents | Weekly |
| `ROADMAP.md` | Now, next, later, each with its gate | Weekly |
| `CAREER_PORTFOLIO.md` | Résumé bullets, stories, quotable numbers with caveats | Weekly, or after a notable change |
| `mockups/` | Fixture-rendered screenshots of the Kalshi page (wide, menu open, phone) | When the page changes |

## Weekly refresh checklist

1. Update the date line at the top of each file.
2. Overview: live record (settled trades, wins, net), balance, variant count, forward-check status, anything new in the incidents list.
3. Roadmap: move finished items to "Done recently", re-read the gates, add what the week opened.
4. Career notes: only numbers that are in the overview; keep the caveat column.
5. Re-render mock-ups if the page changed (the fixture script is described in the PR that added them).
6. Never put keys, account numbers, or the owner's email in these files.
