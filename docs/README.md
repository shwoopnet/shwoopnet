## Weekly refresh checklist

1. Update the date line at the top of each file.
2. Overview: forward-check status, variant count, anything new in the incidents list. No live record figures, balances or sizing bases (owner rule, Nov 12, 2026).
3. Roadmap: move finished items to "Done recently", re-read the gates, add what the week opened.
4. Career notes: only numbers that are in the overview; keep the caveat column.
5. The mock-up screenshots were deleted on 2026-11-13; do not re-add images here.
6. Never put keys, account numbers, or the owner's email in these files.
